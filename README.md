# GrandRead para AltStore Classic

Repositorio de distribución: contiene la fuente de AltStore, el icono y las versiones del instalador. El código de la aplicación se mantiene en un repositorio privado separado.

## Añadir la fuente

En AltStore Classic, abre Sources, pulsa + y añade:

```
https://raw.githubusercontent.com/contactograndread-eng/grandread-altstore/main/source.json
```

Después abre la ficha de GrandRead e intenta instalarla usando tu configuración habitual de AltStore Classic y AltServer.

## Estado de esta versión

- Versión 1.0.0, compilación 1; mínimo iOS 15.5.
- Compilación iOS realizada en Codemagic. IPA sin firma para que AltStore lo firme durante la instalación.
- Esta es una prueba inicial: instalación y funcionamiento pendientes de validación en iPhone real.
- La IA incluida requiere completar App Check de Apple; puede responder con un error 403 mientras esté pendiente. El acceso con Google también debe comprobarse después de la firma.
- Con un Apple ID gratuito, las aplicaciones instaladas con AltStore Classic requieren renovación periódica. Consulta las condiciones y límites de AltStore y Apple.

Esta fuente corresponde a AltStore Classic. No es una publicación en AltStore PAL ni en App Store.
